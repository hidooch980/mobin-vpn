۱برنامه‌ی Hiddify را نصب کنید پیشنهادی

برای آیفون، سرورهای MolidoVPN داخل برنامه‌ی رایگان Hiddify اجرا می‌شوند.

نصب Hiddify از App Store (رایگان)

اگر در App Store پیدا نشد، با یک Apple ID کشور دیگر (مثلاً ترکیه یا امارات) وارد شوید.

۲سرورها را اضافه کنید

بعد از نصب، همین صفحه را در Safari باز کنید و این دکمه را بزنید. اگر پرسید «Open؟»، Open را بزنید.

افزودن به Hiddify

۳وصل شوید

  1. در Hiddify پروفایل MolidoVPN را انتخاب کنید.
  2. حالت را روی «خودکار / Auto» بگذارید تا خودش سرور سالم را پیدا کند و اگر قطع شد عوض کند.
  3. اگر در تنظیمات گزینه‌ی Region: Iran یا «Iran direct» هست، روشنش کنید تا سایت‌های ایرانی بدون VPN باز شوند.
  4. دکمه‌ی بزرگ Connect را بزنید.
  5. پیام افزودن VPN را Allow کنید (ممکن است رمز گوشی یا Face ID بخواهد).

اگر Hiddify نصب نشد یا کار نکرد، یکی از این‌ها را نصب کنید و دکمه‌ی افزودن همان را بزنید.

کدام لینک؟

  • /ios — لینک اصلی آیفون. سرورهایی که از داخل ایران تست شده‌اند اول می‌آیند؛ حداکثر ۸۰ سرور تا حافظه‌ی آیفون پر نشود.
  • /hiddify — همان به‌علاوه‌ی تونل‌های WARP (فقط برای Hiddify).
  • /sub/1 تا /sub/5 — فهرست‌های اضافه؛ ۲ یا ۳ تا را هم اضافه کنید تا اگر یکی از کار افتاد، بقیه کار کنند. همه در بخش لینک‌های اشتراک.

⚠️ اگر سایتی مثل Gemini گفت «در کشور شما در دسترس نیست»

یعنی از طریق WARP یا 1.1.1.1 وصل شده‌اید که کشور خروجی‌اش ایران است. در Hiddify یک سرور V2Ray/Reality (نه WARP) انتخاب کنید و مطمئن شوید پرچم/IP نشان‌داده‌شده کشور دیگری است، نه ایران.

بدون برنامه، از طریق گوشی اندروید خانواده

  1. روی گوشی اندروید: MolidoVPN را وصل کنید ← تنظیمات ← «اشتراک با آیفون و لپ‌تاپ» را روشن کنید.
  2. هات‌اسپات (نقطه‌ی اتصال) اندروید را روشن کنید و آیفون را به آن وصل کنید.
  3. در آیفون: Settings ← Wi-Fi ← ⓘ کنار همان شبکه ← Configure Proxy ← Manual.
  4. Server = آی‌پی‌ای که روی کارت اندروید نوشته شده، Port = 8080 ← Save. (یا QR روی کارت اندروید را با دوربین آیفون اسکن کنید تا آدرس را ببینید.)

لپ‌تاپ ویندوز هم همین‌طور: Settings ← Network ← Proxy ← Manual proxy ← همان IP و پورت 8080.

تونل‌های پشتیبان آیفون

  • Psiphon — وقتی همه‌چیز بسته است؛ خودش راه پیدا می‌کند.
  • 1.1.1.1 — برای وب‌گردی سریع؛ ولی کشور خروجی ایران است (Gemini و مانند آن باز نمی‌شوند).
  • Orbot (Tor) — آخرین راه؛ کند ولی مقاوم (پل Snowflake را روشن کنید).
Psiphon 1.1.1.1 Orbot

آیفون وصل نشد؟

  1. به‌روزرسانی اشتراک — در صفحه‌ی پروفایل‌ها صفحه را پایین بکشید یا دکمه‌ی فلش گرد را بزنید.
  2. تست پینگ — پینگ بگیرید و سروری با عدد سبز انتخاب کنید (نه timeout).
  3. فهرست دیگر — لینک /sub/2 یا /sub/3 را اضافه کنید.
  4. App Store — اگر برنامه پیدا نمی‌شود، Apple ID کشور دیگری لازم است.
  5. DNS گیمینگ — با VPN روشن از Hiddify ← DNS ← Direct DNS؛ بدون برنامه فقط روی Wi-Fi با VPN خاموش (راهنما).

دانلود برای اندروید (بیشتر گوشی‌ها)

گوشی قدیمی اگر نصب نشد

لینک دوم: گوشی قدیمی · همه‌ی گوشی‌ها

۲نصب کنید

  1. فایل دانلودشده را باز کنید و «نصب» را بزنید.
  2. اگر پیام «نصب از منبع ناشناخته» آمد، وارد تنظیمات شوید و اجازه را روشن کنید، بعد برگردید.
  3. اگر Play Protect هشدار داد، «جزئیات» ← «در هر صورت نصب شود» را بزنید.

۳وصل شوید

  1. برنامه را باز کنید و دکمه‌ی بزرگ اتصال را بزنید.
  2. درخواست VPN را «تأیید» کنید. برنامه خودش بهترین سرور را انتخاب می‌کند و اگر قطع شد، خودکار عوض می‌کند.
  3. نیاز به لینک اشتراک نیست؛ همه‌چیز داخل برنامه است.

لینک‌های اشتراک

برای آیفون و برنامه‌هایی مثل Hiddify، Streisand، Karing، v2rayNG و NekoBox. برنامه‌ی اندروید و ویندوز MolidoVPN به این لینک‌ها نیازی ندارد. هر لینک اشتراک ۵۰ تا ۱۰۰ سرور متفاوت دارد؛ ۲ یا ۳ تا از آن‌ها را اضافه کنید تا اگر یک فهرست از کار افتاد، بقیه کار کنند.

فهرست کامل (خیلی بزرگ، مناسب آیفون نیست):

🎮 DNS گیمینگ

این DNSها سرورهای ایرانی مخصوص بازی‌اند: پینگ به سرور بازی‌های آنلاین را کم می‌کنند و بعضی بازی‌های تحریم‌شده را باز می‌کنند. فقط داخل اینترنت ایران کار می‌کنند.

آدرس‌ها

  • رادار گیم: 10.202.10.10 و 10.202.10.11
  • الکترو: 78.157.42.100 و 78.157.42.101
  • شکن: 178.22.122.100 و 185.51.200.2
  • 403: 10.202.10.202 و 10.202.10.102

اگر یکی پینگ خوبی نداد، بعدی را امتحان کنید.

اندروید و ویندوز (برنامه‌ی MolidoVPN)

تنظیمات ← DNS ← یکی از گزینه‌های «DNS گیمینگ». برنامه این DNS را بیرون از VPN می‌فرستد تا از داخل ایران جواب بدهد.

در اندروید، DNS گیمینگ از اندروید ۱۳ به بالا کامل کار می‌کند؛ در نسخه‌های قدیمی‌تر برنامه خودکار DNS عادی را استفاده می‌کند.

DNS گیمینگ همراه با VPN روشن (وای‌فای و اینترنت همراه)

با این برنامه‌ها سایت‌ها و سرورهای بازی ایرانی مستقیم و با DNS گیمینگ می‌روند و بقیه از VPN:

  • آیفون — Hiddify: Settings ← DNS ← «Direct DNS» = 10.202.10.10 (رادار) یا 78.157.42.100 (الکترو)، و Region = Iran / «bypass Iran» روشن.
  • آیفون — Karing: Settings ← DNS ← DNS «Direct» همان آدرس‌ها + قانون (rule set) ایران.
  • اندروید — MolidoVPN: تنظیمات ← DNS ← DNS گیمینگ (بیرون از تونل؛ اندروید ۱۳+).
  • اندروید — v2rayNG: Settings ← «Domestic DNS» = 10.202.10.10 و مسیریابی «Bypass Iran». Hiddify اندروید: مثل آیفون.
  • ویندوز — MolidoVPN: تنظیمات ← DNS ← DNS گیمینگ. Hiddify ویندوز: مثل آیفون.

نام دقیق منوها در نسخه‌های مختلف برنامه‌ها ممکن است کمی فرق کند. آیفون روی اینترنت همراه (بدون VPN) تنظیم DNS ندارد (محدودیت اپل)؛ فقط از طریق این برنامه‌ها یا DNS دستی وای‌فای.

آیفون (بدون VPN، فقط برای بازی)

  1. Settings ← Wi-Fi ← روی ⓘ کنار وای‌فای وصل‌شده بزنید.
  2. Configure DNS ← Manual ← DNSهای قبلی را پاک کنید و دو آدرس یکی از سرویس‌های بالا را اضافه کنید ← Save.
  3. برای برگشت: همان‌جا Automatic را انتخاب کنید.

وقتی VPN روشن است، DNS دستی آیفون استفاده نمی‌شود؛ یا VPN را خاموش کنید یا از روش Hiddify/Karing بالا استفاده کنید.

اگر وصل نشد

  1. پروفایل را به‌روزرسانی کنید — در Hiddify/Streisand/Karing دکمه‌ی به‌روزرسانی (فلش گرد) کنار پروفایل را بزنید تا سرورهای تازه بیاید.
  2. تست پینگ بگیرید — سرورهایی را انتخاب کنید که عدد پینگ دارند، نه «timeout». سرورهای CDN معمولاً بهترین‌اند.
  3. یک لینک اشتراک دیگر امتحان کنید — مثلاً اگر ۱ کار نکرد، ۲ یا ۳ را اضافه کنید.
  4. تونل را عوض کنید — به ترتیب: WARP ← Psiphon ← Tor. (در اندروید و ویندوز از داخل برنامه؛ در آیفون با برنامه‌های پشتیبان.)
  5. DNS گیمینگ فقط داخل ایران — اگر خارج از ایران هستید یا اینترنت عجیب شده، DNS را روی «خودکار» بگذارید.
  6. اینترنت را خاموش/روشن کنید یا بین وای‌فای و اینترنت همراه جابه‌جا شوید.
  7. صفحه‌ی وضعیت سرویس را ببینید — شاید مشکل کلی باشد و به‌زودی رفع شود.

کدام لینک برای کدام برنامه؟
  • برنامه‌ی MolidoVPN اندروید/ویندوز: هیچ لینکی لازم نیست.
  • Hiddify: لینک «Hiddify» (همراه تونل‌های WARP) به‌علاوه‌ی ۲ یا ۳ لینک اشتراک.
  • Streisand و Karing روی آیفون: لینک «آیفون» به‌علاوه‌ی ۲ یا ۳ لینک اشتراک.
  • v2rayNG و NekoBox (اندروید): لینک‌های اشتراک ۱ تا ۵.
  • فهرست کامل: فقط برای برنامه‌های کامپیوتری؛ روی آیفون زیادی بزرگ است.
باتری را زیاد مصرف می‌کند؟

کمی بیشتر از حالت عادی، مثل هر VPN دیگری. Tor و Psiphon مصرف بیشتری دارند؛ وقتی لازم نیست، VPN را خاموش کنید.

چطور به‌روزرسانی کنم؟

اندروید و ویندوز: برنامه نسخه‌ی جدید را خودش اعلام می‌کند؛ «به‌روزرسانی» را بزنید (اندروید قدیمی‌تر از ۲.۰.۴۶: یک بار دستی از همین صفحه نصب کنید). آیفون: در برنامه، پروفایل را به‌روزرسانی کنید؛ سرورها خودکار تازه می‌شوند.

دانلود کند است یا باز نمی‌شود؟

دکمه‌ی اصلی از سرور آینه دانلود می‌کند. اگر کار نکرد، «لینک دوم» (GitHub) را امتحان کنید، یا VPN دیگری روشن کنید و دوباره دانلود کنید.
